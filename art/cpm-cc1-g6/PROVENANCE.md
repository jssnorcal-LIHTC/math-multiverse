# Provenance: `art/cpm-cc1-g6/`

Every asset in this directory is an **original built graphic**, generated deterministically by
`build/polygon-gen.js` from the `dataTable` of its own figure entry in `packs/cpm-cc1-g6.json`.
Nothing here is photographed, scanned, traced, or derived from any third-party source.

**Licence:** original work, produced for this repository.  No third-party rights attach.

**Constraint 8** permits built graphics for charts, maps, schematics, timelines and badges in the
V1 design tokens, which is what these are: labelled polygon schematics for perimeter practice.
Figurative and anatomical content, which these contain none of, would need a verified public-domain
plate or a CC0 photo instead.

**Constraint 5** holds: every asset lives under `art/<packId>/`, and `packs/cpm-cc1-g6.json`
contains no `http://` or `https://` anywhere.

## Regenerating

    node build/cc1-pack-gen.js            rewrites the pack and every SVG here
    node build/cc1-pack-gen.js --check    exits non-zero if either has drifted

`genPolygon` is a pure function of its dataTable and the pack accent colour: no `Date`, no
`Math.random`, no locale-dependent number formatting, every coordinate rounded before it reaches
the string.  Same input, byte-identical output, on every machine.  `tests/figure-reconcile.js`
regenerates each file and byte-compares it, and separately re-derives each item's answer from the
committed dataTable, so a picture cannot silently disagree with the arithmetic beside it.
