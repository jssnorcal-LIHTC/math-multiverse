# Firsthand (G6, History-Social Science): Provenance

Scaffold only.  No figure has been sourced yet for this pack; this file exists so the sourcing
rule below is binding before the first asset lands, not written after the fact to explain one.

**Sourcing rule for this phase.**  CC0, US-federal-PD, or verified-PD-by-edition only.  Two
institution-level exclusions apply and they are structural rather than case-by-case: **no British
Museum photography and no Louvre photography**, regardless of the underlying object's
public-domain status, because both assert their own photographic copyright over photographs of PD
originals.  That puts their signature objects off the candidate list by construction, including the
Rosetta Stone, the Standard of Ur and the Code of Hammurabi stele, and this pack's plan names
fallbacks for each rather than pretending the first choice is available.

Every candidate asset gets verified and logged in the table below BEFORE any pack file references
it.  A figure entering `packs/firsthand-g6.json` without a row here first is itself the defect, not
a formatting gap to fix later.

**Licence authority is the institution's own object page**, not an aggregator, not a search result
and not a Wikipedia caption.  For a Met object that means the object page's own "Public Domain"
marker plus the recorded accession number.  For a PD-by-age scan it means recording the edition
evidence (publication date, and the death dates that establish the term) rather than asserting
"old, therefore public domain."

**The famous piece is often the unlicensed one.**  Where a first-choice object fails verification,
the rejection is logged in the table below with its reason, so a later pass cannot re-derive the
same candidate and re-do the same work, or worse, reach a different conclusion with no record of
why the first one was rejected.
